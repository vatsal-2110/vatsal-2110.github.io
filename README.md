# Vatsal Singhal — Academic Portfolio

A minimal, responsive academic-style portfolio for Vatsal Singhal, built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` contains the profile and research interests.
- `cv.html` is the CV page, ready for your updated resume.
- `news.html` is the News page, ready for future updates.
- `contact.html` contains clickable email addresses.
- `style.css` contains the responsive layout and light/dark themes.
- `script.js` provides the theme toggle, mobile navigation, and current year.
- `favicon.ico` and `favicon.svg` provide browser tab icons.

## GitHub Pages
1. Create a repository named `vatsal-2110.github.io`.
2. Upload all `.html` pages, `style.css`, `script.js`, and favicon files to the repository root.
3. In Settings → Pages, deploy from branch `main`, folder `/ (root)`.
